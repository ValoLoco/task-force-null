# Brain Index

Shared second-brain for all squads. Read at deploy; write via AARs, promoted playbooks, and doctrine updates.

| Path | Purpose |
|------|---------|
| `doctrine.md` | Standing rules, approval gates, Rule-of-Two |
| `aar-log.md` | Outcome / Friction / Fix history |
| `playbooks/_template.md` | Skeleton for new playbooks |
| `playbooks/handoff-protocol.md` | Handoff packet and max-2-hops rule |

**Read order for new deployment:** `doctrine.md` → active `missions/<slug>/mission.md` → `intel.md` → `board.md`.

**Write policy:** Operators append AARs; Lead proposes playbook drafts; Command promotes after Rule-of-Two.
